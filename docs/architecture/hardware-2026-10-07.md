## Design principles (Brian's standing rules)
1. **Autonomy**: every tier runs with zero Hatch dependency — k11 owns schedule, thinking, data, delivery.
2. **Token frugality**: deterministic code first, Sonic second, tokens last.
3. **Separation of concerns**: edge / platform / heavy-data / factories / inference are separate tiers so one failure or one noisy workload doesn't take the rest down.
