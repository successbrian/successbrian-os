## Method for the first assessment

For every system above: name the income mechanism in one line, list
what is missing before the first (or next) dollar, size the missing
piece (days/weeks/months of whose work), and rank. Anything claimed
ready must say ready for *what* — first dollar, first customer, or
repeatable income. Where a missing piece must come before other
work — or is a decision someone must make — set it as a gate in
Atlas (node_type 'gate', status 'pending') instead of leaving it
as prose: gates lead the board's agenda, and dependent work waits
behind them until the gate is cleared (AGENT_CONTRACT rule 17). Every finding leaves as an agenda item (rule 19): a gate if it
must come first or needs a decision, an atlas_task if it needs
work or a ruling — filed in Atlas with its source named
(readiness). Update this file as the ranking changes; the
ranking, not the prose, is the deliverable.
